# Java 변수의 초기값·사용처·변경 위치 — V0.3.0

Java 변수 이름에 커서를 두고 우클릭 → **Explore Variable Relations**를 실행한다.
선언 위치와 사용 위치 모두 가능하다. Java source root에 포함된 지역 변수·매개변수·필드를 지원한다.
인덱싱 중에는 완료를 기다리고 **Variable Relations** 창에 결과를 표시한다.

## 표시하는 관계

| 표시 | 의미 | 예 |
| --- | --- | --- |
| VARIABLE | 선택한 변수 선언 | `int amount` |
| INITIALIZER | 선언에 명시된 초기값 식 | `int amount = input`의 `input` |
| READ | 읽기만 하는 위치 | `if (amount > 0)`, `consume(amount)`, `return amount` |
| WRITE | 대입하는 위치 | `amount = 2`, `(amount) = 4` |
| READ_WRITE | 기존 값을 읽고 다시 쓰는 위치 | `amount += input`, `amount++`, `--amount` |

화살표는 **초기값/쓰기 위치 → 변수 → 읽기 위치**다. READ_WRITE는 양방향 관계를 가진다.
초기값은 변경 위치와 별도 개수로 표시한다. 각 노드의 파일명·줄 번호와 하단의 코드 설명을 확인한다.

이 그래프는 소스에 존재하는 사용·변경 위치를 모은 것이다. 어떤 변경값이 특정 읽기 위치에 도달했는지,
조건문이 실행됐는지, 런타임의 값이 무엇인지는 확정하지 않는다. 초기값 식도 실행하거나 재귀 추적하지 않는다.

## 화면 사용법

- **All**: 선언·초기값·읽기·변경 위치 전체.
- **Reads**: 읽기와 READ_WRITE 위치.
- **Changes**: 초기값·쓰기·READ_WRITE 위치.
- 노드 더블클릭 또는 **Go To Source**: 실제 해당 사용/변경 위치로 이동한다.
- **Show Root**: 선택한 변수 선언 노드를 화면에 표시한다. 큰 그래프는 스크롤로 탐색한다.
- **Refresh**: 편집 후 선언을 기준으로 다시 검색하며 필터는 All로 초기화한다.
- **Cancel**: 진행 중인 검색을 취소한다.

코드나 프로젝트 구성이 바뀌면 snapshot으로 표시한다. 앞에 줄을 삽입해도 스마트 포인터로 이동 위치를 추적한다.
선언이 삭제되면 다른 변수를 선택하도록 안내한다. 창을 숨겼다 열어도 상태를 유지하지만 IDE 재시작 후 복원하지는 않는다.
기존 Code Relations와 JSP Value Origins는 별도 상태로 유지된다.

## 예제와 구분 기준

`samples/VariableExample.java`를 Java source root에 놓고 `amount`를 선택하면
읽기 5곳, 쓰기 2곳, 읽기+쓰기 3곳, 초기값 1개를 볼 수 있다.
동일한 이름이어도 다른 선언을 가리키면 제외한다. 람다 내부도 읽기·쓰기 위치를 수집한다.
JSP 값 역추적이 람다에서 초기값 추론을 멈추는 것과 달리, 여기서는 위치만 나열한다.

필드는 다른 Java 파일의 참조도 검색한다. `a.field`와 `b.field`가 같은 필드 선언이면 둘 다 표시하며,
두 참조가 같은 객체인지 또는 같은 실행 흐름인지는 판정하지 않는다.

`array[i] = value`는 배열 요소를 바꾸지만 `array` 변수 자체는 읽는다.
`obj.field = value`도 `obj`는 읽기이고 `field`는 쓰기다.
`obj.setValue(...)`·`map.put(...)` 호출은 객체를 담은 변수의 재대입으로 분류하지 않는다.
실제 필드 선언을 선택하면 setter 본문의 직접 필드 대입은 일반적인 쓰기 위치로 검색된다.

## 현재 범위와 다음 단계

- 검색은 프로젝트 Java 소스 루트의 정적으로 해석 가능한 참조에 한정한다. 테스트 소스도 포함한다.
- Javadoc, 문자열, 리플렉션, JSP/EL 표현식, 바이너리 내부 참조는 사용 위치로 포함하지 않는다.
- 최대 200개 참조, 참조 방문 20,000회, 약 5초의 협력적 검색 제한을 둔다. 제한에 걸리면 PARTIAL로 표시한다.
  IDE 인덱스 내부 작업까지 강제로 끊는 시간 상한은 아니다. 필터를 바꿔도 누락된 결과를 추가 검색하지 않는다.
- 매개변수·foreach 변수 등에 들어오는 값과 필드의 암묵적 기본값은 별도 초기값 노드로 만들지 않는다.
- 메서드 인자→매개변수, 반환값→받는 변수, getter/setter·Map의 내용 연결은 다음 단계다.

Java 8과 IDEA 2018.3 SDK만 사용한다. 새 외부 라이브러리, 네트워크, AI는 사용하지 않는다.
